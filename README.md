# GREEN-API Test Task

Тестовое задание для GREEN-API.

## Описание
HTML-страница для работы с методами GREEN-API:
- getSettings
- getStateInstance
- sendMessage
- sendFileByUrl

Страница позволяет подключиться к тестовому инстансу GREEN-API и отправлять сообщения и файлы в WhatsApp.

## Как использовать
1. Зарегистрироваться в личном кабинете GREEN-API
2. Создать бесплатный инстанс
3. Отсканировать QR-код и подключить номер телефона
4. Ввести `idInstance` и `ApiTokenInstance` на странице
5. Использовать кнопки для вызова методов API

## Технологии
- HTML
- CSS
- JavaScript (Vanilla JS)
- REST API

## Безопасность
Используется тестовый инстанс. Данные подключения вводятся вручную и не сохраняются.
